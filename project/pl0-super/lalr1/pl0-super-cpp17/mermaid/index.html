状态机图示总览

本页把生成期算出来的状态机画成图：文法侧是 IELR(1) 的 LR 状态机（状态 = LR 项集，边 = GOTO），词法侧是 %token regex / %identifier 编译出的 DFA。下面把所有图都内嵌了一遍，也可以点上面的链接单看图。

  • grammar.html：文法 IELR(1) 自动机（LR 状态机）
  • lexer.html：词法 DFA（每个正则 Token 一张）
  • grammar.mmd：文法图的 Mermaid 源码（可复制到 Markdown 等）
  • lexer.mmd：词法图的 Mermaid 源码

页面用浏览器打开即可看图（图的渲染走 CDN 上的 Mermaid，首次打开需要联网）；图下面折叠的是 Mermaid 源码，同目录的 .mmd 里也有，可以贴到 Markdown 或 mermaid.live 里。

文法自动机（IELR(1) 状态机）

本图共 163 个状态、829 条转移。节点是 IELR(1) 自动机的状态（框里逐项列出 LR 项集，`lalr` / `lr1` / `ielr` 按教材写法把展望符一起写出来），边是 GOTO 转移：开始 指向初态 I0，终结符上标注的是移进、非终结符上另外标 GOTO；状态跑到 接受 说明该状态里有 S' -> S .。每个状态框最后一行“动作：…”就是 ACTION 表里能填出的动作，和颜色一一对应：

  • 蓝：有移进动作
  • 黄：有归约动作（含完整项）
  • 绿：接受状态
  • 红：有未消解冲突（表项按移进优先写，冲突清单见分析报告的 [未消解冲突]）
  • 灰：只有 GOTO 转移

注：虚拟起始符号 __ielr_start 就是教材里的 S'（增广文法新增的那条 __ielr_start -> ielr_start）。

词法 DFA：标识符

正则 [A-Za-z_][A-Za-z0-9_]*，共 3 个状态（双圆 = 接受状态 s2，陷阱状态 s1 与指向它的边已省略）。边上的标签是共享字符类划分后的字符集合，a-z 表示连续区间，空格 表示空格字符。

# 编译原理实验提交要求

- 类型：提交说明
- 来源整理：`Submission.md`
- 处理：已剔除纯作业题单、习题章节和答案内容。

## 本节位置

```mermaid
flowchart LR
    A["OJ 平台"] --> B["提交要求"] --> C["C-- 文法"]
```

1. 通过 OJ 平台提交实验 1-5。
2. 以自己学号命名提交的实验文件，须为完整的压缩 zip 文件， 其中包括所有的源程
序、可执行文件、以及文档。其中，文件组织格式需按课程网站要求，OJ 平台会
自动检查， 不符合要求的无法通过；文档限制在 3 页之内， 超过会扣分； 实验内容
需按照任务分配做，做错会倒扣分。
3. 实验编译方式按所需要求（如指定的 Makefile，那同时也是 OJ 平台批改实验所使
用的 Makefile；这点可能与实验教材/讲义中说的不同，以此为准）。
4. 计划晚交实验的，提前至少 24 小时向老师 email 申请并得到批准，否则视为按时
交实验；OJ 平台会在实验截止时间自动关闭，莫在最后几分钟上传（错过提交时
间无法得到分数）。

# 实验四：目标代码生成

## 1. 实验目标

把实验三生成的 C-- 四元式转换为 MIPS 风格目标代码，完成基本块划分、变量存储分配、
指令选择、标签映射和模拟执行。实验附带后端源码位于 `source/backend/`。

## 2. 总体流程

```mermaid
flowchart LR
    Q["C-- 四元式"] --> B["基本块与 CFG"]
    B --> L["活跃变量分析"]
    L --> R["寄存器/存储位置分配"]
    R --> I["MIPS 指令选择"]
    I --> S["目标机模拟器"]
```

基本块入口包括程序第一条指令、跳转目标和跳转后继。若四元式 $q_i$ 定义变量 $x$，其活跃性方程为：

$$
OUT[B]=\bigcup_{S\in succ(B)}IN[S]
$$

$$
IN[B]=USE[B]\cup(OUT[B]-DEF[B])
$$

## 3. 指令选择

核心映射如下：

| 四元式 | MIPS 风格代码 |
|---|---|
| `(:=, a, _, x)` | 装载 `a` 后存入 `x` |
| `(+:i32, a, b, t)` | 分片装载并执行 `ADD`/`ADDC` |
| `(<:i32, a, b, t)` | 关系比较，结果写入布尔临时量 |
| `(jz, c, _, L)` | 比较零并 `BEQ L` |
| `(j, _, _, L)` | `J L` |
| `(call, f, _, r)` | `CALL f` |
| `(ret:i32, v, _, _)` | 返回值装入约定寄存器后 `RET` |

目标机字长为 16 位，因此 `i32` 值分为两个字处理。加法低半部分使用 `ADD`，高半部分使用带进位的 `ADDC`。

## 4. 生成结果

循环样例的目标代码片段为：

```asm
L_while1:
    RCALL.i32 <, t1, i, 5
    LB.i8 $t0, t1
    CMP.i8 $t0, #0
    BEQ L_endwhile2
    LHU.u16 $t0, i#0
    LI.u16 $t1, 1
    ADD.u16 $t0, $t0, $t1
    SH.u16 $t0, t2#0
    LHU.u16 $t0, i#1
    LI.u16 $t1, 0
    ADDC.u16 $t0, $t0, $t1
    SH.u16 $t0, t2#1
```

生成统计：

```text
四元式：18 条（基本块 5）
目标机：mips（字长 16）；汇编 67 行
模拟：步数 162
输出：15
```

## 5. 正确性验证

验证采用两层对照：

1. `ctest` 对 IR 桥接、数据流、SSA、寄存器分配和流水线执行 8 项测试；
2. 对前端真实生成的 `valid_loop.quad` 进行 MIPS 生成与模拟，检查输出为 `15`。

后端测试结果为：

```text
100% tests passed, 0 tests failed out of 8
```

## 6. 结论

目标代码输入来自严格 C-- 前端，而不是单独手写的四元式。生成的 MIPS 风格程序保持
循环控制流和 32 位算术语义，模拟输出与源程序一致。

# 17 扩展正则表达式

C99 与 C++17 的 `%token regex`、`%identifier`、`%commit`、`%trivia`
支持前瞻、词边界、全局忽略大小写和数字反向引用。
可运行示例为 [regex_extended.gram](../example/regex_extended.gram)。

## 语法与行为

| 功能 | 正则写法 | 行为 |
| --- | --- | --- |
| 正前瞻 | `foo(?=:)` | 只在后面紧跟冒号时匹配 `foo`，不消耗冒号 |
| 负前瞻 | `foo(?!:)` | 后面不是冒号时匹配 `foo` |
| 词边界 | `\bword\b` | 单词字符和非单词字符之间的零宽位置；输入首尾也参与判断 |
| 非词边界 | `a\Bb` | 要求 `a` 与 `b` 之间不是词边界 |
| 全局忽略大小写 | `(?i)abc` | 模式开头的 `(?i)` 对整个模式生效；C99 按 ASCII 字母折叠，C++17 转换为 `std::regex::icase` |
| 捕获及反向引用 | `([a-z]+)-\1` | 第二段必须与第 1 个捕获组的内容相同 |
| 非捕获组 | `(?:ab|cd)` | 分组但不占用捕获编号 |

捕获组从左括号出现顺序开始，按 1、2、3 编号；前瞻里的捕获组也参与编号。
正前瞻成功时的捕获可供后续反向引用使用，但前瞻不消耗输入，成功后不会被外层回溯重新选择。
负前瞻里的捕获不会向外提交。不存在的捕获编号是生成错误。
C99 中，尚未参与匹配的捕获组不能被反向引用；重复组保留最近一次参与捕获的内容。
C++17 的细节遵循当前工具链的 `<regex>` 实现，回归以当前标准库为对照。

词边界中的单词字符是 ASCII `[A-Za-z0-9_]`。字符类里的 `[\b]` 仍表示退格。
`\s` 使用经典字节字符集：空格及 `\t\n\v\f\r`；不会自动把非 ASCII 空白算进去。
`.` 排除 CR 和 LF。字符类两端均可用单字符转义，例如 `[\x41-\x5a]`、`[\u0041-\u005a]`。

忽略大小写目前使用模式开头的 `(?i)`；局部标志 `(?i:...)`、后顾断言和命名反向引用
会给出明确诊断。C99 的扩展匹配器按字节工作，原始 UTF-8 字面量也按其字节序列编译。

## 文法中的写法

`.gram` 的正则字符串保留原有转义规则。下面写的是文法源码，反斜杠需要写两次：

```text
%mode lex
%token COLON ":"
%token regex PAIR "(?i)\\b([a-z]+)-\\1\\b(?=:)"
%space " \t\r\n"
```

输入 `Ab-aB:` 得到 `PAIR("Ab-aB")` 和 `COLON(":")`。
前瞻验证后缀而不消耗后缀，反向引用在忽略大小写模式下也进行 ASCII 大小写折叠。

零宽断言必须与消耗字符的模式组合；单独的 `\b`、`(?=a)` 等规则会被拒绝，
因为词法器不能靠它们向前推进。包含断言和引用时，生成器保守检查可能零宽的规则，
不会通过把断言当空串来生成 DFA。

## 生成产物与匹配顺序

C++17 的 `std` 路径继续使用 `<regex>`；`dfa` 路径对可以保证等价的简单模式生成 DFA，
遇到上下文语法时自动使用标准库。两个入口都识别开头的 `(?i)`，并转换为标准库构造选项。

C99 对普通模式保留 DFA；只要词法配置中有前瞻、边界、反向引用、非贪婪、大小写标志
或原始非 ASCII 模式，就为整份词法配置生成有序正则虚拟机。
有序运行时在单条规则内部保留分支顺序和贪婪／非贪婪顺序；规则之间仍比较匹配长度，
长度相同时沿用声明优先级。普通 DFA 路径仍取最长接受前缀。

运行时通过内嵌模板写进 C 源文件，不需要额外库或磁盘模板。
普通回溯使用堆上的状态快照，前瞻通过子程序执行，捕获在回溯时随快照恢复。
Mermaid 只画能准确表达的 DFA，不会给上下文断言或反向引用生成误导性状态图。

## 回归

```sh
tools/lock.sh build -j4
python tests/regex_extended.py
python tests/cpp_dfa_std.py
```

扩展专项先直接比较虚拟机和 `std::regex` 的首个匹配结果，覆盖嵌套前瞻、捕获回溯、
非贪婪、空循环、UTF-8 字节、转义区间和 ASCII 大小写。随后生成真实 C99、C++17 `std`
和 C++17 `dfa` 词法器，比较 Token、行列、commit 原文、trivia 丢弃、匹配失败和非法规则诊断，
并同时启用 Mermaid 验证生成流程。
